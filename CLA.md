That last point is about *our* releases. MIT lets anyone, you included, use barakoPress inside a
commercial or closed-source product. That is the licence working as intended and nothing here
changes it.

There is nothing to sign. Opening a pull request means you agree to what is below.

These terms apply to contributions from 12 October 2026 and are not retroactive. Before that date,
barakoPress had no written contributor terms, so earlier contributions came in under the
repository's MIT licence alone, which carries no patent grant.

If code is ever copied into this repository from an MPL-2.0 project, those files keep their MPL-2.0
notice. That is deliberate and reviewed, never incidental.

## What is deliberately not here

**No copyright assignment.** Some projects ask you to hand over ownership. This one does not.

**No right to relicense your work as proprietary.** barakoPress is free at any scale, with no paid
edition and no threshold that starts a bill. A permission we would never use is a permission worth
not holding.

**No clause about payment.** Contributions are voluntary, and that goes without saying.

**No signing step.** A bot that is not a required status check blocks nothing while looking like it
does. Contributing is the agreement.
